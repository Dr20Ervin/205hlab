# Contributing to 205hlab

Thank you for taking the time to look at this project! 🎉

## ⚠️ Project Scope

This repository is my **personal production homelab infrastructure** — a live, running system that powers my household daily. It is not a community-maintained project, and I am not accepting pull requests that modify the core stack configurations, as they reflect my specific hardware, network topology, and security decisions.

## ✅ What I Do Welcome

While this is a personal portfolio, the following contributions are genuinely appreciated:

- **Bug reports** — if you spot a misconfiguration, typo, or security concern, please open an issue.
- **Improvements to documentation** — clearer explanations, corrected wording, broken links.
- **Questions and discussions** — if something here sparks curiosity or you want to discuss a design decision, open a GitHub Discussion or an issue.
- **Security disclosures** — please follow the [Security Policy](SECURITY.md) for responsible disclosure.

## 📋 How to Open an Issue

1. Check existing [Issues](https://github.com/Dr20Ervin/205hlab/issues) first to avoid duplicates.
2. Use the appropriate issue template:
   - **Bug Report** — for broken configs, mismatches, or errors.
   - **Feature Request / Suggestion** — for ideas or improvements.
3. Be as specific as possible. Include relevant stack names, file paths, and what you expected vs. what you observed.

## 🔒 Security Issues

**Do not open a public issue for security vulnerabilities.**

Please follow the [Security Policy](SECURITY.md) and report privately to **dr20ervin@outlook.com**.
